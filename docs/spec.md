# 仕様

## 概要

複数のプロジェクトをまたいで再利用できる Claude 用スキル（SKILL.md）や知識ベースを一元管理するリポジトリ。

## 目的

- プロジェクト固有の作業手順や知識をスキルとして抽象化し、横断的に活用する
- 蓄積したスキル・ナレッジを継続的に改善していく
- 新しいプロジェクトへの適用コストを下げる

## スキルとは

Claude（GitHub Copilot）が特定のタスクを実行する際に参照する `SKILL.md` ファイルのこと。
各スキルはディレクトリ単位で管理され、以下の構成を持つ：

```
skills/
  <skill-name>/
    SKILL.md        # スキルの手順・ナレッジ
    examples/       # 使用例（任意）
    templates/      # テンプレートファイル（任意）
```

## スキルの適用範囲

| 種別 | 説明 |
|------|------|
| 汎用スキル | 言語・フレームワーク問わず適用可能なもの |
| 言語別スキル | 特定の言語（TypeScript, Python など）向け |
| フレームワーク別スキル | 特定のフレームワーク（React, FastAPI など）向け |
| ワークフロースキル | CI/CD, コードレビュー, ドキュメント生成など |

## 非機能要件

- スキルは独立して利用可能にする（依存関係を最小化）
- SKILL.md は簡潔かつ実行可能な手順で記述する
- バージョン管理は Git で行う
