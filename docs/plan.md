# 実装計画

## フェーズ 1: 基盤整備

- [x] リポジトリ作成
- [ ] ディレクトリ構成の確定
- [ ] ドキュメント体系の整備（spec / plan / todo / knowledge / development）
- [ ] README の作成

## フェーズ 2: 初期スキルの移植

- [ ] 既存プロジェクトから再利用可能なスキルを洗い出す
- [ ] 各スキルを `skills/<name>/SKILL.md` 形式で整理する
- [ ] スキル一覧を README に記載する

## フェーズ 3: 運用フロー確立

- [ ] 新規スキル追加手順を `docs/development.md` に記載
- [ ] 既存スキルの改善フロー（issue → PR → merge）を定める
- [ ] スキルのカテゴリ・タグ付けルールを決める

## フェーズ 4: 各プロジェクトへの適用

- [ ] 他プロジェクトでの参照方法（git submodule / シンボリックリンク / コピー）を検討・決定
- [ ] 適用手順を `docs/development.md` に追記

## 将来構想

- スキルの自動テスト（SKILL.md の内容に基づいて LLM に実行させて検証）
- スキルのバージョン管理・変更履歴の可視化
- 複数スキルのコンポジション（組み合わせ）パターンの整備
